# Sophia Jensen — portfolio website

A static editorial portfolio built with HTML, CSS, and JavaScript. **No AI-generated images are used.** Project cards currently use styled text placeholders; replace them with your own photographs, screenshots, diagrams, charts, or prototypes when ready.

## Publish with GitHub Pages

1. Create an account at https://github.com/signup . Pick a professional username you are happy to put in your website URL.
2. Create a **public** repository named `YOURUSERNAME.github.io` (substitute your exact username).
3. Click **Add file → Upload files** and drag the **contents of this folder** into the repository root. The `index.html` file must be at the top level, not in a nested directory.
4. Commit the files.
5. Go to **Settings → Pages → Build and deployment**. Choose **Deploy from a branch**, branch **main**, folder **/(root)** and Save.
6. Wait a few minutes and visit `https://YOURUSERNAME.github.io/`.

## Edit the website

- `index.html`: homepage, selected work, About, contact email, and LinkedIn.
- `resume.html`: embedded PDF résumé and download buttons.
- `assets/Sophia_Jensen_Resume.pdf`: your actual one-page résumé PDF. Replace this PDF with a newer version using the same filename.
- `projects/*.html`: individual case studies. All current entries are carefully marked as ongoing or pending visual assets.
- `style.css`: fonts, color scheme, section layout, hover effects, and mobile styling.
- `script.js`: scroll-based reveals with support for reduced motion.

If your browser won't display the embedded PDF, use the **Open résumé in new tab** link.

## Before sharing with recruiters

- Replace placeholder project visuals with real project materials.
- Review/edit all project text and confirm that every statement is accurate and current.
- Confirm whether you want your student email, LinkedIn URL, and contact info in the public résumé.
- Test on desktop and mobile.
